# UIZZE

> **STOP UI SLOP.**

UIZZE is the anti-UI-slop system for coding agents. The free `anti-ui-slop` skill helps Codex, Claude Code, Cursor, Copilot, and other agents stop generic UI before it ships. Full UIZZE adds live search across 800,000+ real web and iOS screens, product-specific design contracts, required states, implementation validation, audits, and rendered critique.

## Start free

Install the skill locally:

```bash
npx skills add https://uizze.com --skill anti-ui-slop
```

Connect the no-account preview for a deterministic rendered UI Slop Gate:

```text
https://uizze.com/mcp/preview
```

## For GitHub teams

Add the local UI Slop Gate to pull requests:

```yaml
- uses: uizze/uizze@v1
```

The Action runs inside the GitHub runner and checks changed frontend files for inert controls, missing states, token drift, and generic UI cues. It does not upload source, screenshots, or findings.
